# Glassbox — TSA HS Webmaster entry

An interactive AI learning portal built with plain HTML, CSS and JavaScript. No frameworks, no website builder.

## Before you submit (checklist)

1. **Team initials**: in `about.html`, replace every `XX` in the Team section with initials only (no full names or school name, since they cost points). Make sure each role matches what that person really did.
2. **Work log**: in `about.html`, replace the Work log table rows with your real Trello entries (dates, task, owner, reviewer).
3. **Copyright checklist**: fill out the official TSA Student Copyright Checklist (Forms Appendix). Save it as `docs/student-copyright-checklist.pdf`, replacing the placeholder.
4. **AI reflection**: copy the content of `docs/resources-and-ai-reflection.pdf` into the **official** TSA Resources and AI Reflection form (4 pages max). Edit it so it describes exactly what your team did, then save it over `docs/resources-and-ai-reflection.pdf`.
5. **Publish**: push this folder to a GitHub repo, then turn on GitHub Pages (Settings → Pages → deploy from branch `main`, folder `/root`). Submit that URL.
6. Test the live URL in Chrome, Edge, Firefox and on a phone.

## Files
- `index.html`: home
- `foundations.html`, `tools.html`, `ethics.html`: the three learning modules
- `dashboard.html`: XP, levels and badges
- `glossary.html`, `about.html`, `references.html`
- `js/progress.js`: XP/badge engine (localStorage)
- `js/labs.js`: the six interactive labs
- `js/quiz.js`: module quizzes (edit questions here)
- `js/glossary.js`: glossary terms
- `css/style.css`: all styles (colors are at the top)
