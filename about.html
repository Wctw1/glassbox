About the project

Built by students, for students

Glassbox is our chapter's entry for the TSA High School Webmaster event. The challenge: design an interactive AI learning portal that helps high school students understand AI, use it well, and use it ethically, with game-style progress tracking to keep them engaged.

Our mission

Make the black box see-through

Most of us use AI tools regularly, but when we started this project we realized we couldn't fully explain how they worked, when they were wrong, or what our school's rules actually allowed. We wanted to build the guide we wished we'd had: short, hands-on, honest about AI's limits, and written in a student's voice.

The name “Glassbox” comes from the opposite of a “black box,” which is a system whose inner workings are hidden. Our goal is for every student to leave able to explain what's happening inside.

Design goals

What we aimed for

  • Learn by doing: six labs that run right in the browser.
  • Accurate and sourced: every fact checked against a credible source (see References).
  • Motivating: XP, five levels and thirteen badges that show progress through each module.
  • Accessible: keyboard navigation, readable contrast, alt text and reduced-motion support.
  • Private: no login, no tracking; progress stays in the student's own browser.

Process

How we built it

  1. Phase 1 · Research

    Understand the challenge

    Broke down the design brief into a requirements checklist, talked about how students actually use AI, and gathered credible sources.

  2. Phase 2 · Plan

    Outline and assign

    TC and LK outlined the modules and chose the three-module structure. We set up Trello like a Gantt chart so everyone could see what they had to do, how to do it, and when.

  3. Phase 3 · Design

    Wireframes and style

    TC and LK sketched the layouts and picked a warm “field guide” look, so it would feel like a notebook, not an ad. That gave the programmers a picture to build from.

  4. Phase 4 · Build

    Code it by hand

    WW and EH built every page with HTML, CSS and plain JavaScript, learning as we went with W3Schools and AI. TC and LK went into the code to change colors and styles. No website builders or templates.

  5. Phase 5 · Test

    Break it on purpose

    Tested the pages in different browsers and on phones, clicked through every lab and quiz, and fixed what broke.

  6. Phase 6 · Refine & launch

    Fix, polish, publish

    Fixed issues from testing, proofread every page, finished the reference page and launched on a public host.

Under the hood

Technology

Glassbox is hand-coded. We did not use a website builder, content management system or front-end framework.

  • HTML5
  • CSS3
  • JavaScript (ES5+)
  • Canvas API
  • Inline SVG
  • localStorage
  • Google Fonts
  • W3Schools
  • Git & GitHub
  • GitHub Pages
  • Trello

Progress is saved with the browser's localStorage, so it works without accounts and no student data ever leaves the device.

For everyone

Accessibility

  • Text and background colors were checked against WCAG 2.2 contrast guidelines.
  • Every page works with a keyboard alone, with a “Skip to content” link and visible focus outlines.
  • Diagrams include text descriptions for screen readers.
  • Layouts adapt to phones, tablets and desktops.
  • Animations are turned off for users who prefer reduced motion.
